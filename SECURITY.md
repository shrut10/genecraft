# Security policy

Please report suspected security issues using GitHub's **Report a vulnerability** feature on the GeneCraft repository. Do not include working exploit details, OAuth tokens, or private world data in a public issue.

The local bridge is designed for a single machine and binds to `127.0.0.1`. It is not intended to be exposed to the internet or used as a shared hosted service. Model actions are limited and validated by the Paper plugin. Please include affected versions and a minimal reproduction in a private report.
